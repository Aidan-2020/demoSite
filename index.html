A place to begin.

This prototype starts with illustrative demo locations. They do not represent Downtrace’s interests.

Add or edit locations, search and filter the atlas, then export a GeoJSON file. Imports accept a GeoJSON FeatureCollection of Point features with name, country, type, status, priority, and notes properties. Import replaces the current atlas after confirmation.

Your changes stay in this browser; this version has no shared database or live feeds. Export before moving devices or clearing browser data.

Map: Leaflet with OpenStreetMap tiles. The dark treatment is applied locally. The GeoJSON format provides a common foundation for a future Unity / Cesium viewer.
