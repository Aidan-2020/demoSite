A place to begin.

This prototype starts with illustrative demo locations. They do not represent Downtrace’s interests.

Click Add site, then click the map to set its position. Enter a name, choose Client or Potential client, and save. Use Manage sites for direct Edit and Remove buttons. Removal offers Undo. Export a GeoJSON file to back up your work. Imports accept a GeoJSON FeatureCollection of Point features with name, country, type, status, priority, and notes properties. Imports add new sites to the shared atlas after confirmation.

Demo mode stores records in Firebase. Company-server mode reads and writes records only through your SSH tunnel, using a separate server token. Disconnect clears this tab's token. In company mode, the map uses offline country outlines instead of external tiles. Authorized browsers receive the data needed to display it.

Private 3D twin opens the company's viewer in a new tab. Copy pin ID, then use add_model.py on the server to attach a local GLB to that pin. The viewer asks for the server token separately. Real site metadata belongs in company mode until external storage is approved.

Map: Leaflet with OpenStreetMap tiles. The dark treatment is applied locally. The GeoJSON format provides a common foundation for a future Unity / Cesium viewer.
